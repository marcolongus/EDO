# Ecuaciones Diferenciales Ordinarias

Este repositorio reúne el material de clase de **Ecuaciones Diferenciales Ordinarias**. Está disponible para que los estudiantes puedan consultar las notas, los trabajos prácticos y el material complementario del curso.

> [!IMPORTANT]
> **Este repositorio es un trabajo en progreso.** Los apuntes se encuentran en preparación y pueden cambiar durante el cursado. Es posible que todavía contengan errores, secciones incompletas o diferencias respecto de lo desarrollado en clase.

## Cómo usar el repositorio

- Los archivos PDF son la opción más cómoda para leer el material.
- Los archivos `.tex` contienen el código fuente de los apuntes.
- Antes de estudiar una clase, conviene comprobar que se esté usando la versión más reciente.
- Las indicaciones dadas durante la clase tienen prioridad si existe alguna diferencia con estos documentos.

## Contenido

| Carpeta | Contenido |
|---|---|
| `Clase I/` | Introducción, definiciones básicas, problemas de valor inicial y ecuaciones lineales. |
| `Clase II/` | Existencia y unicidad, formas de representar soluciones y campos de direcciones. |
| `Clase III/` | Ecuaciones autónomas, integración directa, variables separables y problemas de modelado. |
| `Suplementario/` | Material adicional para profundizar conceptos y discusiones teóricas. |
| `Trabajos prácticos/` | Guías de ejercicios de la asignatura. |
| `Programa/` | Programa de la materia. |
| `Bibliografía/` | Bibliografía de consulta. |

## Sobre posibles errores

Si encontrás un error de escritura, de notación o de contenido, podés comunicarlo al docente. Estas observaciones ayudan a mejorar el material para todo el curso.

## Compilación

Para modificar o compilar las fuentes se necesita una distribución de LaTeX. Por ejemplo:

```bash
pdflatex "Clase I/clase_I.tex"
```

No es necesario compilar los documentos para utilizarlos: las versiones en PDF se incluyen en el repositorio.
